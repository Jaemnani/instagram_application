# 초단축 재생성 프롬프트

`SITE_PROMPT.md` 의 700자 버전도 길다고 거절당하는 도구용.

줄이는 순서는 이렇게 잡았다 — **결과물을 보면 알 수 있는 것부터 버리고,
말해주지 않으면 반드시 다시 밟는 것을 마지막까지 남긴다.**
그래서 색상은 3개만, 함정은 `keep-all` 하나만 남았다.

---

## A. 약 350자

```
서울 성수동 베이비·가족 사진 스튜디오 kidding seongsu 홈페이지. Next.js + Tailwind, 정적 생성.

에디토리얼 매거진 톤(인스타 UI 흉내 금지). 배경 #fdfcfa, 글자 #1c1917, 액센트 테라코타 #b4694e.
제목 Noto Serif KR, 본문 Noto Sans KR. 슬로건 "No posed, Just Kidding!" — 연출된 포즈 대신
아이가 노는 사이의 표정.

헤더 없이 한 페이지: 전체화면 히어로 → 스튜디오 소개 → 촬영 종류 4개(돌사진/백일·성장/
가족사진/스튜디오 렌탈) → 최근 촬영(대표 1장 + 가로 스크롤) → FAQ → 오시는 길.
외부 링크는 "촬영 예약 문의" 하나만.

한·영·일·중 4개 언어. AI 검색 노출이 목적이라 LocalBusiness·FAQPage JSON-LD 필수,
JS 없이도 본문이 보여야 함. word-break: keep-all 은 한국어에만(일·중은 화면 밖으로 넘침).
```

## 쓰는 법

A로 먼저 만들게 한 뒤, **다음 메시지로 아래를 던지면** 긴 버전과 비슷한 품질이 나온다.
대부분의 도구는 첫 프롬프트만 길이를 제한하고 이어지는 대화는 여유가 있다.

```
추가 요구사항:
1. word-break: keep-all 은 :lang(ko) 에만. 일본어·중국어는 띄어쓰기가 없어 문장 전체가
   안 끊기고 화면 밖으로 넘친다
2. 대형 워드마크는 브레이크포인트 계단식 금지 → clamp(1.5rem, calc((100vw-4rem)/10), 5.5rem)
3. 가로 스크롤은 scroll-padding 을 padding 과 같은 값으로
4. 함수가 든 사전 객체를 클라이언트 컴포넌트에 넘기면 빌드 실패 → 문자열로 변환해 전달
5. 촬영 종류는 01~04 번호를 달고 한 화면에 전부. 갤러리는 자동으로 흐르게 하지 말고
   다음 카드가 잘려 보이게 + 화살표
6. 검색어는 직역 말고 그 언어권 실제 표현으로(영 Seoul baby photo studio,
   일 ソウル ベビーフォト, 중 首尔儿童摄影工作室). 중국어에 라틴 studio 금지 → 工作室
```
